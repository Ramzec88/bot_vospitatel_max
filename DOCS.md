# Помощник воспитателя — MAX бот

Бот для мессенджера MAX, который помогает воспитателям детских садов генерировать педагогические материалы с помощью ИИ.

---

## Сервисы и инфраструктура

| Компонент | Сервис |
|-----------|--------|
| Хостинг бота | Railway (Node.js контейнер) |
| База данных | PostgreSQL на Railway (shared с Telegram-ботом) |
| ИИ-генерация | OpenRouter API (модель: `anthropic/claude-3.5-sonnet` по умолчанию) |
| Мессенджер | MAX (`max.ru`) |
| Репозиторий | GitHub: `ramzec88/bot_vospitatel_max` |

---

## Переменные окружения (Railway → Variables)

| Переменная | Описание |
|------------|----------|
| `MAX_BOT_TOKEN` | Токен бота MAX |
| `DATABASE_URL` | Строка подключения к PostgreSQL |
| `OPENROUTER_API_KEY` | API-ключ OpenRouter |
| `OPENROUTER_MODEL` | Модель ИИ (опционально, по умолчанию `anthropic/claude-3.5-sonnet`) |
| `ADMIN_IDS` | ID администраторов через запятую (например `8839861`) |
| `BOT_USERNAME` | Username бота в MAX (например `id320203526914_bot`) — нужен для реферальных ссылок |
| `PORT` | Порт (Railway задаёт автоматически) |

## База данных

Таблицы создаются автоматически при старте бота (`CREATE TABLE IF NOT EXISTS`).  
Так как БД общая с Telegram-ботом, для добавления новых колонок используются безопасные миграции (`ALTER TABLE ... ADD COLUMN IF NOT EXISTS`).

### Таблица `users`
| Колонка | Тип | Описание |
|---------|-----|----------|
| `user_id` | BIGINT PK | ID пользователя в MAX |
| `tier` | TEXT | Тариф: `free`, `premium`, `admin`, `none` |
| `platform` | TEXT | Платформа: `max` или `telegram` |
| `bonus_generations` | INT | Накопленные бонусные генерации от рефералов |
| `created_at` | TIMESTAMPTZ | Дата регистрации |
| `updated_at` | TIMESTAMPTZ | Дата обновления |

### Таблица `generations`
| Колонка | Тип | Описание |
|---------|-----|----------|
| `id` | SERIAL PK | — |
| `user_id` | BIGINT | Кто сделал запрос |
| `content_type` | TEXT | Тип: `scenario`, `methodical`, `activity`, `game` |
| `platform` | TEXT | `max` или `telegram` |
| `description` | TEXT | Текст запроса от пользователя |
| `created_at` | TIMESTAMPTZ | Дата генерации |

### Таблица `referrals`
| Колонка | Тип | Описание |
|---------|-----|----------|
| `referrer_id` | BIGINT | Кто пригласил |
| `referred_id` | BIGINT UNIQUE | Кого пригласили (уникальный — нельзя засчитать дважды) |
| `created_at` | TIMESTAMPTZ | Дата регистрации реферала |

## Тарифная система

| Тариф | Генераций в месяц | Как получить |
|-------|------------------|--------------|
| `free` | 5 | Автоматически при первом запуске |
| `premium` | 30 | По диплинку `?start=premium_access` |
| `admin` | ∞ | Указан в `ADMIN_IDS` |
| Реферальный бонус | +5 за каждого | Навсегда, не сбрасывается |

Лимит = базовый тариф + бонусные генерации.  
Бонусные генерации накапливаются и **не сбрасываются** каждый месяц.  
Базовый лимит сбрасывается **1-го числа каждого месяца**.

## Команды бота

| Команда | Описание |
|---------|----------|
| `/start` | Открыть главное меню |
| `/limits` | Показать тариф, использованные и оставшиеся генерации, реферальную ссылку |
| `/referral` | То же, что `/limits` — показывает реферальную ссылку |
| `/cancel` | Отменить текущую генерацию |
| `/analytics` | **Только для администраторов.** Статистика: пользователи по тарифам, генерации за день/месяц по типам |

## Диплинки

Диплинки — ссылки вида `https://max.ru/BOT_USERNAME?start=PAYLOAD`.  
Позволяют автоматически установить тариф или засчитать реферала.

| Payload | Действие |
|---------|----------|
| `premium_access` | Установить тариф `premium` (30 генераций/месяц) |
| `free_access` | Установить тариф `free` |
| `ref_USERID` | Засчитать реферала, начислить +5 генераций пригласившему |

---

## Процесс генерации (FSM — конечный автомат)

Генерация проходит через 4 шага:

1. **Выбор типа контента** — кнопки в главном меню:
   - 📋 Сценарий мероприятия
   - 🎵 Методический материал
   - 🎨 Конспект занятия
   - 🎮 Описание игры

2. **Возрастная группа** — 3–4, 4–5, 5–6, 6–7 лет

3. **Размер группы** — малая (до 10), средняя (10–20), большая (20+)

4. **Описание задачи** — пользователь пишет произвольный текст (например: «Весенний утренник, тема — природа просыпается»)

После этого запрос уходит в OpenRouter, ответ разбивается на части (MAX ограничивает сообщение 4000 символами) и отправляется пользователю.

## Реферальная программа

- Каждый пользователь имеет уникальную реферальную ссылку (видна в `/limits`)
- Ссылка: `https://max.ru/BOT_USERNAME?start=ref_USERID`
- Когда новый пользователь переходит по ссылке:
  - Ему автоматически устанавливается тариф `free`
  - Пригласившему начисляется **+5 генераций** навсегда
  - Пригласившему приходит уведомление в боте
- Один пользователь может быть засчитан как реферал только один раз (защита от накрутки)

## Администрирование

Отправьте боту `/analytics` — придёт сообщение:
- Всего пользователей и разбивка по тарифам
- Генераций сегодня
- Генераций в текущем месяце по типам контента
- Кнопка **📋 Последние запросы** — показывает последние 20 генераций с датой, ID пользователя, тарифом, типом и текстом описания
- Кнопки **◀️ / ▶️** для листания (пагинация по 20)
